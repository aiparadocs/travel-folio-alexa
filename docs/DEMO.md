# A trip becomes a memory

This is a proposed walkthrough for the working demo, not a claim that a video has
already been recorded. Keep the Alexa+ simulation and weather-source labels visible.

## Suggested three-minute walkthrough

1. **0:00–0:20 — The idea.** “At home, talk through the trip. On your phone, turn
   that same itinerary into a scrapbook.” Show the form and the conversation.
2. **0:20–0:55 — Make a plan.** Choose Kyoto, two days, relaxed pace, coffee and
   culture. Review the creation card and confirm. Point to the actual itinerary.
3. **0:55–1:25 — Respond to rain.** Check weather. Say explicitly that the default
   uses sample rain for a reproducible demo. Propose an indoor swap, inspect the
   before/after card, and confirm. Demonstrate Undo if time permits.
4. **1:25–2:20 — Take it along.** Show the QR and open its link on the phone (same
   Wi-Fi) or a narrow browser. Confirm the import. Choose a stop, add a personal
   photo and a short caption, then select a sticker.
5. **2:20–2:45 — Keep the result.** Show the memories page, export the whole journal,
   and explain that the file contains the photos and words.
6. **2:45–3:00 — What is real.** “The trip operations, MCP requests, confirmation,
   handoff and journal work. Alexa+ is simulated. Bedrock and live weather are
   optional server settings.”

Use original or authorized photos. The app does not create pretend personal
memories. Do not describe demo weather as an actual forecast. Bedrock mode was
verified live once (2026-10-09, Amazon Nova 2 Lite in Tokyo); the default demo does not use it.

## Short prompts

- “Plan a relaxed two-day Kyoto trip with coffee and culture.”
- “Check weather.”
- “Swap rainy stops for indoor places.”
- “Move day 1 thirty minutes later.”
- “Undo.”
- “Take it to my phone.”

For the voice walkthrough, select English and press **Start conversation** once.
Say the prompts, wait for each reply to finish, and use “Yes, use this plan” to
approve exactly what was read. “Take it to my phone” opens the handoff and ends
listening. Use the Phone launcher for a scan-ready LAN address. Actual microphone
and phone scanning must be checked before recording; browser availability varies.

The visible confirmation buttons, typing and quick actions remain available.
The phone copy and home plan do not automatically sync. Start still requires an
explicit browser click; this is not a physical Echo wake-word integration.
